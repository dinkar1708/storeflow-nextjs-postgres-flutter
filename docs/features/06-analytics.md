# Feature: Sales Analytics

**What:** Real-time sales analytics and reporting dashboard for business insights.

**Who needs it:** Store owners and admins who need to track sales performance and make data-driven decisions.

---

## API Endpoints

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/api/analytics/sales` | GET | Yes (ADMIN) | Get sales metrics |

---

## Metrics Available

- Total sales revenue
- Order count
- Average order value
- Sales by category
- Top selling products
- Revenue trends (daily, weekly, monthly)
